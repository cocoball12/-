# 디스코드 프라이빗룸 봇

새로운 멤버가 서버에 참가할 때 자동으로 프라이빗 룸을 생성하고 안내 메시지를 보내는 디스코드 봇입니다.

## 기능

- 새 멤버 참가 시 자동으로 프라이빗 채널 생성
- 단계별 안내 메시지 전송
- 인터랙티브 버튼을 통한 사용자 선택
- 채널 삭제/유지 기능

## 설치 방법

1. 필요한 패키지 설치:
```bash
pip install -r requirements.txt
```

2. 환경변수 설정:
   - `.env.example` 파일을 `.env`로 복사
   - 디스코드 봇 토큰을 입력

3. 봇 실행:
```bash
python bot.py
```

## Render 배포 설정

### 환경변수
- `DISCORD_BOT_TOKEN`: 디스코드 봇 토큰

### 빌드 명령어
```bash
pip install -r requirements.txt
```

### 시작 명령어
```bash
python bot.py
```

## 봇 권한 설정

봇이 제대로 작동하려면 다음 권한이 필요합니다:

- 채널 관리 (Manage Channels)
- 메시지 보내기 (Send Messages)
- 메시지 읽기 (Read Messages)
- 역할 관리 (Manage Roles)
- 멤버 보기 (View Members)
- 임베드 링크 (Embed Links)

## 사용법

1. 봇을 서버에 초대
2. 새 멤버가 서버에 참가하면 자동으로 "괄자-애정듬뿍-{사용자명}" 채널이 생성됩니다
3. 안내 메시지와 버튼을 따라 진행하세요

## 주의사항

- 봇은 "스튜어디스" 역할을 자동으로 생성합니다
- "프라이빗 룸" 카테고리를 자동으로 생성합니다
- 버튼은 해당 사용자만 클릭할 수 있습니다
